# Documentación del proyecto

Esta carpeta contiene la documentación técnica y de usuario del frontend.

## Archivos

- `ManualTecnico.md` — descripción de la arquitectura, proveedores, hooks, servicios y decisiones técnicas.
- `ManualUsuario.md` — guía para el usuario final sobre cómo usar la aplicación.
- `glosario.md` — términos y conceptos importantes del proyecto.
- `UML.md` — diagramas UML y relaciones entre entidades.

## Imágenes

Las imágenes asociadas a la documentación se encuentran en la misma carpeta y son utilizadas en los documentos técnicos.

## Cómo usarla

Abre cualquiera de los archivos `.md` para ver los detalles de implementación, las rutas, los flujos de datos y las decisiones de diseño.
